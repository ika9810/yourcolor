# YourColor 첫 버전 기능 선택과 화면 설계

> **2026-10-10 후속 결정:** 사용자가 자동 구도 생성 방향을 폐기했다. 현재는 색선을 직접 고르고 자유롭게 워프하는 수동 편집을 우선한다. 아래 자동 생성 관련 설계는 이전 안이며, 최신 HTML 시안과 구현 범위는 [디자인 시안 02](../design-prototypes/README.md)를 따른다. 네이티브 반영과 최종 글꼴은 아직 확정하지 않았다.

2026년 10월 10일 갱신. 사용자는 **사진을 넣으면 자동으로 결과를 만들고, 같은 화면에서 직접 조정하는 흐름**을 선택했고, 이후 네이티브 프로젝트 준비와 핵심 흐름 구현을 승인했다. [Android 검증 앱](../../android/README.md)을 구현했으며 아래 추가 선택지는 제안으로 유지한다. V20 성능과 출시 범위는 미확정이다. 기존 조건은 [리빌딩 기획](pixel-stretch-brief.md)을 따른다.

이 흐름을 기준으로 상세 설계 진행이 승인됐다. 화면별 동작, 처리 순서, 저장 규칙과 다음 검증 단계는 [첫 버전 상세 설계](v1-detailed-design.md)에 정리했다. 이 문서는 기능 선택 목록으로 유지한다.

사용자가 첨부한 사진 컬렉션 앱의 밝은 배경·둥근 카드·넉넉한 여백을 시각적 기준으로 선택했다. 기존 와이어프레임은 동작 검토용이며, 실제 화면의 표현은 상세 설계의 시각적 방향을 따른다.

**기본 구성 B를 먼저 제안한다.** 사진 한 장으로 편집과 저장을 마치는 데 필요한 구성이다. 기본 구성도 수정할 수 있다.

| ID | 기능 | 첫 버전의 제안 범위 |
| --- | --- | --- |
| B1 | 사진 선택 | 시스템 사진 선택기에서 한 장 열기, 방향 정보 반영, 확대·이동 |
| B2 | 픽셀 스트레치 | 색을 뽑는 선의 위치, 늘릴 방향과 길이, 효과 한 개 |
| B3 | 곡선 편집 | 직선과 기본 곡선, 소수의 조절점으로 휘어짐 수정 |
| B4 | 실수 복구와 비교 | 실행 취소·다시 실행, 원본과 비교 |
| B5 | 저장과 공유 | JPG 이미지 저장, 시스템 공유, 원본 파일 보존 |

**추가 기능은 번호로 선택한다.** 비용은 유료 API 사용료가 아닌 구현·검증 부담을 뜻한다. 모든 항목은 유료 API 없이 구현할 수 있는 후보이며, 앱 판매 가격은 별도 결정이다. 아래 부담은 상대적인 설계 추정이다.

| 번호 | 기능 | 사용자가 얻는 것 | 추가되는 화면 또는 조작 | 판단 |
| --- | --- | --- | --- | --- |
| 1 | 자동 피사체 분리 | 인물·사물을 스트레치 효과 앞에 올린다. | 편집 화면의 피사체 표시 스위치와 초기 준비 상태 | 추천. 분리 품질과 기기 호환성 검증 필요 |
| 2 | 수동 복원 브러시 | 누끼가 틀린 부분을 덧칠하거나 지운다. | 피사체 도구의 복원·제외·브러시 크기 | 추천. 확대·실행 취소와 연계 |
| 3 | 구도 프리셋 3개 | 직선·아치·S자 예시에서 시작한다. | 편집 화면에서 필요할 때 다른 구도 선택 | 추천. 개수와 모양은 미정 |
| 4 | 사진에 맞춘 초기 구도 | 피사체 위치를 보고 색선·방향·곡선의 초기값을 제안한다. | 프리셋을 현재 사진에 맞춘 결과 후보로 표시 | 차별화 검증 후보. 1과 3 필요, 품질 검증 부담 큼 |
| 5 | 투명도와 끝 흐리기 | 효과 강도를 줄이고 끝을 자연스럽게 연결한다. | 편집 화면의 마무리 도구 | 추천. 비교적 작은 추가 범위 |
| 6 | 출력 비율과 자르기 | 정사각형·4:5·9:16으로 저장할 구도를 잡는다. | 저장 화면의 비율 선택과 자르기 | 선택. 피사체가 잘리지 않는지 확인 필요 |
| 7 | 여러 스트레치 레이어 | 한 사진에 효과를 여러 개 겹친다. | 레이어 목록, 추가·복제·삭제·순서 변경 | 후속 권장. 편집 상태와 메모리 관리 증가 |
| 8 | 짧은 영상 저장 | 사진 속 스트레치가 움직이는 짧은 영상을 만든다. | 움직임 도구, 재생 미리보기, MP4 저장 설정 | 선택. 작업량과 기기별 검증 부담 큼 |
| 9 | 편집 프로젝트 보관 | 앱을 닫았다가 조절값을 그대로 이어 편집한다. | 시작 화면의 최근 작업, 프로젝트 저장 | 후속 권장. 사진 접근 권한과 작업 데이터 관리 필요 |
| 10 | 사진 색상 팔레트 카드 | 사진의 주요 색을 카드로 함께 저장한다. | 저장 화면의 팔레트 카드 옵션 | 후속 아이디어. 핵심 스트레치 경험과 별도 |

2는 자동 분리 없이도 원본에서 앞에 보여줄 부분을 손으로 칠하는 방식으로 제공할 수 있다. 4는 1과 3이 함께 있어야 한다. 8은 여러 레이어 없이 효과 한 개로도 가능하다. 기능을 선택해도 사진 외부 전송 없음, 자체 백엔드 없음, 사용량 API 요금 없음 조건은 유지한다.

**추천 조합은 기본 구성과 1·2·3·4·5다.** 사용자가 선택한 자동 생성과 직접 조정 경험을 이 조합으로 구현하는 안을 제안한다. 1·3·4는 이를 위한 우선 기술·기능 후보이고, 추천 개수와 브러시·마무리 도구까지 모두 선택한 것으로 해석하지 않는다. 4의 자동 구도가 자주 어긋나면 3의 고정 프리셋 중심으로 범위를 줄일지 사용자가 판단한다. 영상 저장 8은 아직 선택하지 않았다.

**현재 와이어프레임은 자동 결과와 직접 편집을 합친다.** 기존 A의 자동 구도와 B의 바로 편집을 한 화면에서 제공한다. 자동·수동 모드를 먼저 선택하게 하지 않는다.

사진 선택 S1 → 자동 결과와 편집 S3 → 저장 S4

| 화면 | 위쪽 | 가운데 | 아래쪽 | 다음 동작 |
| --- | --- | --- | --- | --- |
| S1 시작 | YourColor, 개인정보 안내 진입 | 겹친 결과 예시 카드 | 사진 선택 버튼 | 시스템 사진 선택기를 거쳐 S3로 이동 |
| S3 편집 | 뒤로, 실행 취소·다시 실행, 저장 | 자동 결과 한 개, 원본 비교, 필요한 경우 준비 안내 | 다른 구도, 색선·모양·피사체·마무리 도구 | 자동 결과 그대로 저장하거나 같은 화면에서 수정 |
| S4 저장 | 편집으로 돌아가기 | 최종 미리보기 | 형식·크기, 저장·공유 | 저장 완료를 같은 화면에 표시 |

사진 선택 취소는 S1에 머문다. 기존 S2 구도 선택은 필수 화면에서 제외하고, S3의 다른 구도 선택 영역으로 합친다. 구도를 바꿔도 사진과 분리 결과를 재사용한다. 편집 내용이 있을 때 나가기는 버리기·계속 편집을 제공하고, 9를 고르면 프로젝트 보관도 추가한다.

**자동 처리가 늦어도 편집을 막지 않는 동작을 제안한다.**

| 상태 | 화면과 동작 |
| --- | --- |
| 사진을 여는 중 | 축소 미리보기를 준비한다. 아직 사진을 읽지 못했으면 사진 준비 중이라고 표시한다. |
| 사진은 준비됐지만 자동 결과는 대기 중 | 기본 효과를 먼저 보여 주고 직접 조정할 수 있게 한다. 사진에 맞춘 추천 준비 중임을 표시하며 완료된 자동 결과처럼 부르지 않는다. |
| 수정하기 전에 자동 결과 도착 | 추천 구도와 피사체 복원을 함께 적용한다. 실행 취소 가능하게 한다. |
| 사용자가 먼저 수정한 뒤 자동 결과 도착 | 현재 편집과 피사체 상태를 보존한다. 추천 적용 버튼을 보여 주고, 눌렀을 때만 바꾼다. 적용은 실행 취소할 수 있다. |
| 최초 모델 다운로드 또는 실패 | 원인을 짧게 안내한다. 기본 편집·저장을 허용하고 준비 또는 재시도 동작을 제공한다. |
| 저장 또는 사진 교체 | 저장은 선택 시점에 보이던 편집 상태를 사용한다. 뒤늦은 추천으로 저장 내용이 바뀌지 않는다. 이전 사진의 작업 결과는 새 사진에 적용하지 않는다. |

자동 생성은 사진 전체를 생성형 AI로 다시 그리는 기능이 아니다. 한 번 얻은 피사체 마스크와 위치를 이용해 색선·방향·곡선을 정하고 원본 픽셀로 효과를 합성하는 방식을 우선 검토한다. 여러 구도와 조절값 변경마다 AI를 재실행하지 않는다. 같은 사진·같은 설정에는 같은 효과를 그리는 것을 목표로 하며, 자동 구도의 임의 무작위 선택은 기본값에 넣지 않는다.

미리보기는 축소 해상도로 먼저 처리하고, 저장용 고해상도 렌더링은 따로 한다. 너무 작은 AI 입력은 누끼 품질을 해칠 수 있으므로 입력 크기는 실측으로 정한다. Google은 정확한 분리를 위해 최소 512×512 입력을 권장한다. [Android 성능 안내](https://developers.google.com/ml-kit/vision/subject-segmentation/android)

**체감 속도 목표의 초안은 첫 미리보기 1초 이내, 모델이 준비된 상태의 자동 결과 2초 이내다.** 사진 선택기가 앱에 제어를 돌려준 시점부터 재며, 확정 요구사항이나 측정 결과가 아니다. 최신 비교용 기기와 V20을 별도로 측정한다. 모델 다운로드와 세션 첫 추론은 별도 기록하며 평균뿐 아니라 느린 경우도 확인한다. 목표보다 늦어도 조정·저장을 막지 않는다.

Google의 공개 수치는 Pixel 7 Pro에서 피사체 분리 평균 약 200ms다. 사진 읽기·미리보기·구도 계산·합성까지 합친 자동 결과 시간이나 V20 수치가 아니다. 첫 모델 다운로드가 필요할 수 있고, 세션 첫 추론은 초기화 때문에 더 느릴 수 있다. 구현 승인 후의 첫 기술 검증은 이 전체 시간과 누끼·구도 품질을 함께 측정하는 작업으로 제안한다. [분리 성능 안내](https://developers.google.com/ml-kit/vision/subject-segmentation), [다운로드·초기화 안내](https://developers.google.com/ml-kit/vision/subject-segmentation/android)

**선택한 기능에 따라 다음과 같이 화면을 바꾼다.**

| 기능 | 화면 변화 |
| --- | --- |
| 1·2 제외 | 피사체 도구를 숨긴다. 원본 위에 스트레치 효과만 합성한다. |
| 1만 포함 | 피사체 표시 스위치를 제공한다. 실패하면 수동 일반 편집을 계속할 수 있다. |
| 2 포함 | S3의 피사체 도구에 복원·제외·크기를 제공한다. 자동 분리 결과가 없어도 직접 칠할 수 있다. |
| 3 제외 | 다른 구도 선택을 숨기고 하나의 기본 구도로 편집을 시작한다. |
| 4 포함 | 1과 3을 함께 포함한다. 구도 후보와 시작선·방향을 사진에 맞춰 준비한다. |
| 5 포함 | 마무리 도구에서 효과 투명도와 끝 흐리기를 조절한다. |
| 6 포함 | S4에 출력 비율과 자르기를 추가한다. |
| 7 포함 | S3에 레이어 선택·관리 영역을 추가한다. |
| 8 포함 | S3에 움직임 도구를, S4에 MP4 형식과 길이·해상도 설정을 추가한다. |
| 9 포함 | S1에 최근 작업을, S3에 프로젝트 저장을 추가한다. |
| 10 포함 | S4에 팔레트 카드 저장 옵션을 추가한다. |

**오류 상태에서도 편집을 이어갈 수 있게 설계한다.** ML Kit의 첫 모델 다운로드가 필요하면 준비 상태와 수동으로 계속하기를 보여준다. 다운로드 또는 자동 분리가 실패하면 재시도와 수동 편집을 제공한다. 선택한 사진의 사람이나 사물을 제대로 찾지 못하면 2의 브러시로 수정하거나 피사체 복원을 끌 수 있다. 이미지·영상 저장 실패는 편집 상태를 유지하고 재시도하도록 한다.

처리 중에는 완료 전의 결과를 완성된 누끼처럼 표시하지 않는다. 와이어프레임의 도형 사진과 효과는 화면 배치 예시이며 실제 분리·구도 추천·사진 렌더링 결과가 아니다. 클릭으로 화면과 옵션을 확인할 수 있지만 실제 사진 업로드나 파일 저장은 수행하지 않는다. 자동 분리 준비·실패 상태도 설계 검토용 예시다.

**남은 선택은 세부 기능에 한정한다.** 핵심 흐름의 검증 앱을 먼저 구현했다. 추가로 “브러시 2 포함 / 영상 8 보류”처럼 정할 수 있다. 추천 조합이나 와이어프레임의 초기 선택은 승인된 출시 범위가 아니다.
