# YourColor 픽셀 스트레치 리빌딩 기획

> **2026-10-10 후속 결정:** 사용자가 자동 구도 생성 방향을 폐기했다. 현재는 색선을 직접 고르고 자유롭게 워프하는 수동 편집을 우선한다. 아래 자동 생성 관련 설계는 이전 안이며, 최신 HTML 시안과 구현 범위는 [디자인 시안 02](../design-prototypes/README.md)를 따른다. 네이티브 반영과 최종 글꼴은 아직 확정하지 않았다.

2026년 10월 10일 기준. 제품 방향과 사용자 조건을 기록하고, 구현 후보와 차별화 가설을 구분한다. 사용자가 네이티브 프로젝트 준비와 핵심 흐름 구현을 승인하여 `android/`에 검증 앱을 구현했다. 출시 범위·스토어 공개 승인은 별도다.

첫 버전의 번호별 선택지와 화면 흐름은 [기능 선택과 화면 설계](v1-features-and-wireframes.md)에서 검토한다. 자동 결과와 직접 조정을 합친 경험은 사용자가 선택했다. 세부 기능과 구현 방법은 제안이며 전체 출시 범위가 확정된 것은 아니다.

선택한 통합 흐름의 [첫 버전 상세 설계](v1-detailed-design.md)를 기준으로 구현했다. 실제 실행 방법과 구현·검증 범위는 [Android 안내](../../android/README.md)를 따른다.

YourColor의 이번 리빌딩은 사진의 색을 늘려 직선이나 곡선 효과를 만드는 안드로이드 사진 편집 앱을 중심으로 진행한다. 기존 퍼스널컬러 진단 기능의 최종 유지·삭제 여부는 아직 정하지 않았다. 앞서 수행한 진단 모델 비교는 [평가 보고서](../evaluation-2026/2026-10-10/report.txt)에 보존한다.

**합의한 방향과 조건은 다음과 같다.**

| 항목 | 현재 결정 또는 조건 |
| --- | --- |
| 제품 방향 | 픽셀 스트레치를 중심으로 리빌딩을 설계한다. |
| 핵심 경험 | 사진을 넣으면 자동으로 효과를 만들고, 같은 화면에서 사용자가 조정할 수 있게 한다. 자동 처리 대기 시간을 줄이는 것을 중시한다. |
| 시각적 방향 | 사용자가 첨부한 사진 컬렉션 앱처럼 밝은 배경, 넉넉한 여백, 둥근 사진 카드와 부드러운 그림자로 깨끗하면서 예술적인 인상을 만든다. 세부 적용안은 상세 설계에 둔다. |
| 플랫폼 | 안드로이드 네이티브 앱으로 만든다. |
| 사진 처리 | 사진을 외부 서버로 전송하지 않고 기기 안에서 처리한다. |
| 운영 구조 | 자체 백엔드를 사용하지 않는다. 사진 처리 횟수에 따른 API 요금이 없어야 한다. |
| 유지보수 | 단순한 구조로 운영 부담을 최소화한다. Android·Play 변경 대응까지 없어지는 것은 아니다. |
| 참고 앱 | LEAP STUDIO의 Pixel Stretch를 기능과 편집 흐름의 참고 대상으로 삼는다. |
| 보유 기기 | LG V20에서 동작하면 좋지만 필수 출시 조건은 아니다. |
| 작업 방식 | 설계를 먼저 검토한다. 문서화 요청을 앱 구현 승인으로 해석하지 않는다. |
| 저장소 | API 키, 서명 파일, 사용자 이메일을 넣지 않는다. |

AI는 자동 피사체 분리의 구현 후보다. 픽셀 스트레치 효과 자체에는 학습 모델이 필요하지 않다. SDK의 무료 제공과 앱의 판매 가격은 별개이며, 광고·구독·일회성 구매·무료 범위는 아직 정하지 않았다.

**첫 버전의 기능 범위는 아직 제안 단계다.**

사용자가 선택한 편집 흐름은 사진 선택 → 자동 결과가 있는 편집 화면 → 필요하면 직접 조정 → 저장·공유다. 별도 구도 선택 화면을 반드시 거치지 않도록 설계한다. 자동 피사체 분리 결과를 사용하면 인물이나 사물을 늘어진 효과 위에 다시 올릴 수 있다. 프리셋 개수, 복원 브러시, 영상 저장 등 세부 범위는 아직 제안이다.

| 기능 후보 | 목적 | 범위 상태 |
| --- | --- | --- |
| 사진 선택, 확대와 이동 | 효과를 넣을 사진과 부분을 고른다. | 기본 기능 제안 |
| 색을 뽑는 선 이동 | 늘어나는 색의 조합을 바꾼다. | 기본 기능 제안 |
| 직선과 곡선, 방향과 길이 조절 | 원하는 위치로 색을 늘린다. | 기본 기능 제안 |
| 자동 피사체 분리와 복원 | 피사체를 효과 앞에 배치한다. | 우선 검증 후보 |
| 수동 복원 브러시, 실행 취소 | 분리 경계나 편집 실수를 수정한다. | 품질 보완 제안 |
| 이미지 저장과 공유 | 편집 결과를 다른 곳에서 사용한다. | 기본 기능 제안 |
| 여러 레이어, 투명 그라데이션, 색조와 왜곡 | 복잡한 표현을 만든다. | 첫 버전 포함 여부 미정 |
| 움직이는 효과와 영상 저장 | 사진 한 장에서 짧은 영상을 만든다. | 구현 가능성 검토됨, 출시 시점 미정 |

참고 앱에는 곡선 편집, 사용 가능한 기기에서의 피사체 복원, 이미지 저장이 명시돼 있다. 업데이트 내역에는 여러 레이어, 투명 그라데이션, 무작위 모양, 왜곡, 색조, 애니메이션 영상이 포함돼 있다. 이 목록을 YourColor의 확정 개발 범위로 간주하지 않는다. [App Store 소개와 업데이트 내역](https://apps.apple.com/us/app/pixel-stretch/id6779071913)

**현재 검증 앱은 Kotlin, Android Canvas, ML Kit를 사용한다.** 초기 OpenGL ES 제안을 단일 Canvas 렌더러로 단순화했다. 이후 실기기 측정에서 부족한 경우 렌더링 방식을 재검토한다.

| 구성 요소 | 후보와 판단 |
| --- | --- |
| 앱 | Kotlin 기반 네이티브. 상세 설계에서는 단일 앱 모듈과 Android Views·GLSurfaceView·ViewModel 조합을 초기 검증안으로 제안한다. |
| 효과 렌더링 | Canvas의 비트맵 메시로 구현했다. 미리보기와 JPG 출력에 같은 계산을 사용하며 V20 실기기 성능은 아직 검증하지 않았다. |
| 자동 피사체 분리 | Google ML Kit Subject Segmentation을 우선 검증한다. |
| 최소 지원 OS | Android 7.0, API 24를 후보로 둔다. 최종 지원 범위는 미정이다. |
| 영상 저장 | Android의 Media3 Transformer와 MediaCodec 기반 구성을 검토한다. |

OpenGL ES는 구형 안드로이드에서도 사용할 수 있고, Media3 Transformer는 Android 6.0 이상을 지원한다. 이는 사용할 수 있는 기반 기술의 조건이며 V20의 실제 편집 속도나 영상 저장 성능을 보장하지 않는다. [OpenGL ES 공식 문서](https://developer.android.com/develop/ui/views/graphics/opengl/about-opengl), [Media3 Transformer 공식 문서](https://developer.android.com/media/media3/transformer)

ML Kit는 무료 SDK이며 피사체 분리 대상에 사람, 반려동물, 전경의 사물이 포함된다. 자체 모델 학습과 추론 서버 없이 사용할 수 있다. [ML Kit 무료 제공 안내](https://developers.google.com/ml-kit/guides), [Subject Segmentation 기능 설명](https://developers.google.com/ml-kit/vision/subject-segmentation)

Subject Segmentation은 Android 7.0 이상과 Google Play 서비스를 사용한다. 모델을 처음 내려받을 때 인터넷이 필요하고, 준비된 모델의 사진 처리는 오프라인으로 가능하다. 현재 베타이므로 API 변경과 호환성 대응 가능성은 남는다. 설치 직후부터 모델 다운로드 없이 동작해야 한다는 조건은 아직 정하지 않았다. [Android 설치 조건](https://developers.google.com/ml-kit/vision/subject-segmentation/android)

사진과 분리 결과는 Google 서버로 전송하지 않는다. SDK는 모델 업데이트 등을 위해 통신하고 성능·사용 통계를 전송할 수 있으므로, 이를 반영해 개인정보 안내와 데이터 보안 항목을 작성해야 한다. [ML Kit 개인정보 처리 설명](https://developers.google.com/ml-kit/terms)

**V20은 선택적 지원 목표로 검증한다.**

LG의 출시 사양은 Android 7.0, Snapdragon 820, RAM 4GB다. ML Kit 피사체 분리의 OS 조건에는 들어가지만 보유 기기의 현재 OS, Google Play 서비스 상태, 모델 실행 여부와 처리 시간은 실기기로 확인해야 한다. [LG V20 공식 사양](https://www.lg.com/us/cell-phones/lg-LS997-Boost-v20)

성능을 위한 설계 제안은 사진을 불러올 때 피사체를 한 번 분리하고, 그 영역 정보인 마스크를 이후 편집과 애니메이션에서 재사용하는 것이다. 곡선 조절이나 영상의 매 프레임마다 AI를 다시 실행하지 않는다. 미리보기에는 축소 이미지를 사용하고 저장용 렌더링은 별도로 처리한다.

자동 결과가 늦으면 사진과 기본 효과를 먼저 보여 주고 편집을 허용한다. 이때 기본 효과는 사진에 맞춘 추천이 완료된 결과와 구분한다. 추천이 준비됐을 때 아직 수정하지 않았다면 적용하고, 이미 수정했다면 현재 편집을 보존한 채 추천 적용 버튼을 제시한다. 최초 모델 다운로드·세션 첫 추론·준비된 상태의 추론 시간을 따로 측정한다. 이는 설계 제안이며 V20에서 검증한 동작은 아니다.

구현 승인 후 V20에서 먼저 확인할 것은 자동 분리의 성공 여부와 소요 시간, 곡선을 움직일 때의 반응성, 큰 사진을 불러오고 저장할 때의 메모리 사용이다. 짧은 영상 저장은 그다음 검증 후보로 둔다. 해상도·레이어 제한, 수동 복원으로의 대체, V20 지원 제외 중 어떤 대응을 택할지는 측정 후 결정한다. V20 지원 때문에 주된 편집 경험을 얼마나 제한할지도 아직 정하지 않았다.

**경쟁 앱 대비 장점은 아직 검증할 가설이다.**

| 비교 대상 | 공개 설명에서 확인한 내용 | YourColor에 주는 의미 |
| --- | --- | --- |
| [Pixel Stretch — LEAP STUDIO](https://apps.apple.com/us/app/pixel-stretch/id6779071913) | Apple 플랫폼에서 곡선 편집, 조건부 피사체 복원, 여러 레이어, 영상 저장 등을 제공한다. | 주요 기능의 구현 가능성을 참고할 수 있다. 동일한 기능 목록만으로 우위가 생기지는 않는다. |
| [Pixel Stretch Pro — Emre Ertunç](https://play.google.com/store/apps/details?hl=en&id=com.emreertunc.pixelstretch) | Android에서 색 선택, 직선·사용자 지정 경로, 고품질 이미지 저장, 기기 내 사진 처리를 안내한다. | 안드로이드 시장에도 전용 경쟁 앱이 있다. Android 지원이나 오프라인 처리만으로 차별화하기 어렵다. |

위 비교는 스토어와 공식 안내에 따른 기능 비교다. 직접 사용한 결과가 아니므로 경쟁 앱의 조작감, 누끼 품질, 속도가 나쁘다거나 소개에 없는 기능이 없다고 단정하지 않는다. 참고 앱의 안내도 색을 뽑는 선과 곡선 조절이 결과에 중요하다고 설명한다. [Pixel Stretch 편집 안내](https://pixel-stretch.com/guides/how-to-make-pixel-stretch-effect-on-iphone.html)

우선 검토할 차별화 가설은 **편집을 잘 모르는 사람도 적은 조작으로 공유하고 싶은 결과를 얻는다**는 것이다. 후보 사용자도 아직 제안 단계이며, 우선 피사체 하나가 뚜렷한 사진을 편집하려는 사람으로 좁혀 검증한다.

구체적인 설계 제안은 피사체 위치에 맞춘 한 가지 구도를 편집 화면에 자동 적용하고, 다른 구도는 원할 때 고르게 하는 방식이다. 색을 뽑는 위치와 효과 방향의 초기값을 추천하고, 사용자는 길이·휘어짐 등을 직접 수정한다. 기존 분리 결과와 기하 계산을 활용하는 접근을 먼저 검토하며 추가 AI 모델을 필수로 두지 않는다. 사진에 따라 초기 구도가 어울리지 않을 수 있으므로 자동 선택의 품질은 별도 검증 대상이다.

| 차별화 후보 | 사용자에게 줄 가치 | 판단 |
| --- | --- | --- |
| 사진에 맞춘 초기 구도와 소수의 프리셋 | 시작 위치와 곡선을 여러 번 고치는 수고를 줄인다. | 우선 검증할 가설 |
| 피사체가 잘 보이는 합성과 쉬운 복원 | 얼굴·옷·물체 경계를 손질하기 쉽게 만든다. | 완성도를 위한 보완 요소. 자동 누끼 기능 자체는 독점적 강점이 아니다. |
| 정지 이미지에서 짧은 영상까지 이어지는 흐름 | 완성한 편집을 다시 만들지 않고 영상으로 저장한다. | 후속 후보. 참고 iOS 앱에도 있으므로 사용성과 품질로 비교해야 한다. |

한국어 안내, V20 지원, 오프라인 처리, 가격은 보조적인 선택 이유가 될 수 있다. 핵심 강점으로 삼을지는 사용자 반응을 보고 결정한다. 특히 무료 SDK를 쓴다는 사실만으로 앱도 전부 무료여야 한다는 결론을 내리지 않는다.

**차별화 검증은 같은 사진과 같은 작업으로 비교하는 방식을 제안한다.**

먼저 접근 가능한 경쟁 앱에서 사진 선택부터 저장까지의 흐름을 직접 확인한다. 구현 전에는 두세 가지 결과 예시와 화면 흐름으로 제안한 경험을 검토하고, 구현 승인 뒤에는 작은 프로토타입으로 다음을 비교한다.

- 사용자가 마음에 드는 첫 결과를 저장하기까지 걸린 시간과 완료 여부.
- 색을 뽑는 선, 곡선, 피사체 경계를 직접 수정한 횟수와 어려웠던 부분.
- 결과물의 앱 이름을 가렸을 때 어느 이미지를 선호하는지와 그 이유.
- V20과 비교용 최신 기기에서의 편집 반응성, 분리 시간, 저장 성공 여부.

현 단계에서 경쟁 앱보다 빠르거나 예쁘다는 수치 목표를 성과처럼 제시하지 않는다. 초기 구도 추천이 실제로 수정을 줄이고 결과 선호도를 높일 때 우선 투자할 근거가 생긴다. 차이가 작으면 기능을 늘리기 전에 대상 사진이나 편집 흐름을 다시 검토한다.

**범위를 넓히는 아이디어는 후속 검토를 제안한다.**

사진의 색상 팔레트 카드, 여러 사진의 일괄 편집, 템플릿 라이브러리, 실시간 카메라 효과는 확장 아이디어다. 첫 버전의 기본 제안에서는 제외하며 최종 포함 여부는 미정이다. 추가 모델이나 운영 시스템이 필요한 기능은 유지보수 목표와 함께 검토한다.

**사용자가 이후 결정할 항목은 남겨 둔다.**

- 첫 버전에 포함할 기능과 영상 저장의 우선순위.
- 자동 분리 실패 시 허용할 수동 편집의 정도와 첫 모델 다운로드 흐름.
- 최종 최소 지원 OS와 V20 지원을 위해 감수할 품질·성능 제한.
- 처음 공략할 사용자와 사진 유형, 차별화 가설의 채택 여부.
- 최종 앱 이름과 스토어 소개, 광고·가격·무료 사용 범위.
- 기존 등록 업데이트 또는 새 앱 출시, 기존 진단 기능의 최종 처리.

기존 등록을 업데이트한다면 패키지 이름 `com.robotics.yourcolor`와 기존 평점·리뷰가 이어진다는 원래 브리프의 조건을 반영한다. 재출시 때 공동 제작자 표기와 동의를 챙기고, 기존 연예인 사진·이름은 새 앱 자산으로 사용하지 않는다. 서명과 Play 요구사항, 개인정보처리방침과 데이터 보안은 출시 방식을 정한 뒤 새 기능 구성에 맞춰 준비한다.
