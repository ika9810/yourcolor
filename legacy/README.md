# 보관 자료

현재 배포 소스는 저장소 루트의 `android/`와 `docs/`입니다. 이 폴더의 자료는 과거 구현과 검토 기록이며 새 앱의 기능·정책을 설명하지 않습니다.

| 경로 | 내용 |
| --- | --- |
| [`personal-color-2022/`](personal-color-2022/) | 2022년 퍼스널 컬러 웹사이트와 당시 정적 자산 |
| [`planning/`](planning/) | 2026년 픽셀 스트레치 초기 기획·설계 초안 |
| [`design-prototypes/`](design-prototypes/) | v1–v4 HTML 디자인 시안, 빌드 스크립트와 참고 이미지 |
| [`branding-explorations/`](branding-explorations/) | 채택 전 로고·그래픽 방향 검토 |
| [`evaluation-2026/`](evaluation-2026/) | 초기 퍼스널 컬러 모델 평가 기록 |

개인 연락처가 포함된 오래된 템플릿과 회의·계정 화면, 공동작업자 정보가 든 발표 원본은 현재 공개본에서 제외했습니다. Git의 이전 커밋에는 과거 파일이 남을 수 있으므로 공개 이력은 별도로 정리해야 합니다.
