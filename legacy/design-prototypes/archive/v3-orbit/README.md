# YourColor 디자인 시안 03 — 미디어아트와 직접 조작

2026-10-10. 사용자의 ‘미디어아트 느낌이 부족하고 조작이 어렵다’는 피드백에 따른 **제안 시안**이다. `yourcolor-design-v3.html`에서 동작한다. 기존 v2는 비교용으로 그대로 보존했다. Android 구현이나 출시 기능 확정은 아니다.

## 이번 실험

사진과 조절점 8개를 한꺼번에 보여주는 방식을 없애고, **느낌 고르기 → 사진 위를 끌기 → 이미지 저장**으로 줄였다. 편집 화면을 바로 보여준다. 작은 화면에서는 아래 도구함, 큰 화면에서는 사진 옆 도구함으로 배치한다. 효과 버튼의 썸네일도 현재 사진으로 그린다.

- **흐름:** 사진의 한 줄에서 뽑은 RGB 색 띠를 두 개의 연결된 곡선을 따라 흘린다. 곡선의 법선 방향, 폭 변화, 명암으로 접히는 띠의 깊이를 표현한다. 드래그하면 곡선의 모양이 바뀐다.
- **궤도:** 같은 색 띠를 타원형으로 감는다. 뒤쪽 반원을 그리고 피사체를 합성한 후 앞쪽 반원을 그려 실제로 앞뒤가 나뉜다. 드래그하면 기울기와 위치가 달라진다. 3D 엔진이 아니라 Canvas 합성이다.
- **잔상:** 실제 분리된 피사체를 축소·회전·이동해 겹친다. 드래그 방향에 따라 퍼지는 방향이 바뀐다. 픽셀 스트레치에서 넓힌 표현 후보이며 출시 포함 확정이 아니다.
- 공통 슬라이더 하나가 띠의 폭·궤도의 크기·잔상의 퍼짐을 조절한다.
- 먹색/종이색/원본 바탕 선택. 어두운 바탕과 명암으로 효과가 잘 드러나게 하고, 앱 도구는 밝고 단정하게 유지한다.
- 색 위치는 버튼을 누른 뒤 사진을 탭해서 변경한다. 잔상에는 색선이 없으므로 해당 버튼을 비활성화한다.
- 피사체 보정은 사진의 ‘피사체 · 다듬기’를 눌러 필요할 때 연다. 재인식·보호/지우기·브러시 크기·전경 유지 스위치를 제공한다.
- 실제 JPG/PNG/WebP 가져오기, 프로젝트별 편집 상태, 실행 취소/다시 실행, 원본 비교, 저장 미리보기를 유지한다.

샘플 사진은 표현을 보여주기 위해 수동으로 정한 효과와 초기값으로 시작한다. **가져온 사진에는 효과를 자동으로 적용하지 않는다.** 피사체만 분리한 후 사용자가 효과를 골라야 한다. 효과를 바꾸거나 드래그할 때 AI를 다시 실행하지 않는다.

## 범위와 제한

- 기기 내 분리는 v2에서 검증한 `u2netp` + ONNX Runtime Web Worker를 재사용한다. 모델과 런타임을 로컬에 동봉했으며 사진 업로드나 원격 추론 API가 없다. [출처와 라이선스](README.md#분리-모델과-런타임-출처).
- 샘플 배치를 위해 원본 투명 이미지의 범위를 읽지만, 실제 편집 마스크는 샘플과 가져온 사진 모두 모델로 추론한다.
- 320px 입력의 작은 모델이라 머리카락, 가는 팔·줄기, 복잡한 배경에서 경계가 거칠거나 빠질 수 있다. 어두운 바탕에서 밝은 테두리가 드러날 수 있다. 보정 브러시를 남겼으며 품질이 해결됐다고 주장하지 않는다.
- 모든 조정은 정지 이미지 편집이다. 동영상·애니메이션 내보내기는 추가하지 않았다. Android/V20 실행 성능은 이번 HTML 검증으로 알 수 없다.
- 작업 영역은 4:5, 원본 캐시는 960×1200이다. 가져온 사진은 전체가 보이도록 맞추므로 가로 사진의 피사체가 작아 보일 수 있다. 사진 크롭/재배치 도구는 이번 시안에 없다.
- 1440×1800 JPG 출력은 캐시를 확대한 결과이며 원본 해상도 보존을 의미하지 않는다. 캔버스 위 편집 안내나 작은 영문 라벨은 저장하지 않는다.
- 편집 내용은 메모리에만 있고 새로고침하면 사라진다.
- 브라우저 저장 기능은 기존 다운로드 동작을 유지했다. 이전 턴에 인앱 브라우저가 blob 링크 열기를 보안 정책으로 차단했으므로 이번에는 그 동작을 재시도하지 않고 저장 미리보기까지만 확인한다.

## 실행

저장소 루트에서:

```sh
python3 legacy/design-prototypes/build_v3.py
python3 -m http.server 8767 --bind 127.0.0.1 --directory legacy/design-prototypes
```

http://127.0.0.1:8767/yourcolor-design-v3.html

소스: `src/v3.html`, `src/v3.css`, `src/v3.js`. 분리 Worker는 공용 `src/segment-worker.mjs`를 그대로 사용한다. `vendor/`와 `models/`도 함께 제공해야 한다. 빌드에 npm 설치는 필요 없다.

## 검증

- 내장 브라우저의 기본 1280px 화면과 375×812px 모바일 폭에서 확인. 모바일에서도 효과 선택, 슬라이더, 바탕, 저장 버튼이 보인다. 테스트용 viewport override는 확인 후 해제한다.
- 실제 포인터 드래그로 궤도 기울기/위치가 바뀌고 안내가 사라짐, 실행 취소로 드래그 전 상태 복구 확인.
- 흐름·궤도·잔상에 서로 다른 결과가 생성됨을 확인.
- Mac의 375px 화면에서 드래그 후 단일 Canvas 렌더 명령 수행 시간 약 3.1ms를 관측했다. 전체 프레임 시간/FPS, Android, V20 수치는 아니다.
- 일반 JPG를 파일 선택기로 가져오면 효과 미선택 원본 상태에서 시작하며, 선택 후 기기 내 분리 마스크를 합성하는 흐름을 검증한다. 원본 사진은 rembg 공식 테스트 예제이며 제품 샘플로 추가하지 않았다.
- 사용 글꼴·샘플 이미지·모델 출처는 기존 `provenance.json`과 [v2 기록](README.md)을 따른다. 새 이미지를 외부 생성 API로 만들지 않았다.

- 추가 검증: 일반 JPG 피사체 분리 완료 약 1.2초, 보정 브러시로 팔 영역 지우기 및 실행 취소 확인. 색 위치를 탭하면 편집 결과로 돌아오며 색 띠가 달라진다. 저장 모달에서 UI 라벨 없는 결과와 1440×1800 Canvas 확인. JPG 파일 다운로드 완료는 이번 검증 범위에 포함하지 않았다.
