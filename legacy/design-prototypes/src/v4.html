이번 디자인 제안

시작 → 사진 선택 → 편집 → 저장으로 이어지는 전체 화면 시안입니다. 상단의 보기 전환과 글꼴 비교는 디자인 검토용 도구예요.

피사체의 실제 픽셀을 네 방향으로 늘리는 기존 기능을 유지했습니다. ‘직접 사용’에서 샘플이나 내 사진으로 편집해보세요. 가져온 사진에는 효과를 자동으로 적용하지 않아요.

사진은 이 기기에서만 처리하며, 새로고침하면 편집은 사라집니다. 저장 화면은 미리보기이고 ‘이미지 저장’을 눌러 파일 다운로드를 요청합니다. Android 화면 구현과 V20 성능 검증은 다음 단계입니다.
