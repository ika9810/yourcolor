# YourColor UI 시안 04 — 전체 흐름과 글꼴 선택

2026-10-11. 밝고 정돈된 사진 중심 UI로 전체 흐름을 다시 만든 **디자인 제안**이다. 사용자 첨부 레퍼런스의 흰 테두리, 겹쳐진 사진, 넓은 여백, 부드러운 그림자와 파스텔 색을 반영했다. ‘Apple이라면’이라는 요청은 정보 위계와 단순한 조작을 중시하는 방향으로 해석했다. Apple 공식 디자인이나 확정된 제품 사양을 의미하지 않는다. Android 소스는 변경하지 않았다.

## 확정 문구와 글꼴

- 메인: **너의 순간을, / 조금 더 길게.**
- 설명: **사진 속 색을 펼쳐 만드는 / 나만의 픽셀 스트레치.**
- 글꼴: **페이퍼로지**. 앱 화면의 기본 폰트와 비교용 문구에 함께 반영했다.
- 시작 화면의 부가 문구는 정리하고, 기기 내 처리 안내는 사진 선택 화면으로 옮겼다.

## 보기와 선택

- [전체 시안](http://127.0.0.1:8767/yourcolor-design-v4.html)
- **전체 흐름**: 시작 → 사진 선택 → 편집 → 저장을 나란히 비교. 좁은 창에서는 화면을 세로로 배치한다.
- **직접 사용**: 한 화면씩 실제로 이동하며 조작. 작은 화면의 기본 보기다.
- **Aa 글꼴 / 글꼴 3종 비교하기**: 같은 크기와 문장을 각 후보의 실제 폰트로 표시. 선택하면 모든 앱 화면에 적용한다. 디자인 검토 도구이며 앱에 폰트 설정 기능을 넣기로 확정한 것이 아니다.
- 글꼴 이름만 `localStorage`의 `yourcolor-v4-font-confirmed`에 기억한다. 사진과 편집 내용은 메모리에만 있으며 새로고침하면 사라진다.

## 화면 구성

1. 시작: 실제 스트레치 결과를 겹친 작품 카드, 짧고 큰 제목, 사진 선택으로 이어지는 버튼 하나를 강조. 카드도 눌러 해당 샘플의 편집을 시작할 수 있다.
2. 사진 선택: 내 사진 가져오기와 샘플 3개. 인물·자동차·꽃 모두 실제로 선택된다. 가져온 사진에는 효과를 자동 적용하지 않고 모양 선택부터 시작한다.
3. 편집: 작품을 크게 보여주고, **늘리기 / 모양 / 피사체 / 바탕**으로 도구를 나눈다. 현재 필요한 패널 하나만 노출한다. 위·아래·왼쪽·오른쪽, 길이, 시작선, 직선·펼침·곡선, 마스크 보정, 원본 비교, 실행 취소/다시 실행을 유지한다.
4. 저장: 실제 렌더된 결과와 출력 정보를 보여준다. **저장 완료를 가장하지 않는다.** ‘이미지 저장’ 버튼은 기존 JPG 다운로드 요청 코드로 연결되고, ‘조금 더 다듬기’는 편집 상태를 유지한 채 돌아간다.

계정, 서버 갤러리, 커뮤니티, 별도 작품 보관함 등은 추가하지 않았다. 상단 화면 이동과 글꼴 비교는 검토용 UI다.

## 타이포그래피 제안

작은 영문 장식과 빽빽한 도구 라벨을 줄이고 한글 제목, 본문, 조작 요소를 구분했다. 색은 사진에 맡기고 주요 행동과 선택에만 파랑을 사용한다. 앱의 타이포그래피는 하나의 후보 글꼴로 통일하며 로고는 별도 브랜드 이미지로 유지한다.

- 주요 제목: 약 30–38px / 700 / 짧은 줄과 좁은 자간.
- 내비게이션 제목: 17px / 600.
- 설명: 15–17px / 400 / 1.5–1.6 줄 높이.
- 주요 버튼: 15–16px / 600.
- 도구: 12–14px, 보조 정보는 11–12px.
- 세 후보의 비교 카드는 제목 31px / 700, 설명 16px / 400으로 동일하게 구성한다. 모바일에서는 비교 제목 34px이며 세 카드 모두 같은 기준이다.

| 후보 | 디자인상 추천 이유 (의견) | 눈누 | 원 저작자 / 라이선스 |
|---|---|---|---|
| 프리텐다드 — 비교 후보 | UI의 존재감을 줄이고 사진에 집중하기 좋다. | [눈누 프리텐다드](https://noonnu.cc/font_page/694) | [orioncactus/Pretendard](https://github.com/orioncactus/pretendard), SIL OFL 1.1 |
| SUIT | 단정하고 또렷한 도구 화면에 어울린다. | [눈누 SUIT](https://noonnu.cc/font_page/845) | [SUNN](https://sun.fo/suit/), SIL OFL 1.1 |
| 페이퍼로지 — 사용자 확정 | 제목에 넓고 기하학적인 개성을 주는 대안이다. | [눈누 페이퍼로지](https://noonnu.cc/font_page/1456) | [페이퍼로지 공식 배포](https://freesentation.blog/paperlogyfont), SIL OFL 1.1 |

눈누의 등록 페이지와 사용 범위 및 원 배포처를 확인했다. 기존에 로컬로 확보한 폰트와 라이선스를 재사용한다. 파일을 런타임에 외부 CDN에서 불러오지 않는다. 라이선스는 `assets/*-LICENSE.txt`와 빌드 HTML 안에 동봉한다. 2026-10-11 사용자 선택으로 페이퍼로지를 확정했다. 기존 비교 때 저장된 폰트가 확정안을 덮어쓰지 않도록 저장 키를 분리했다. 비교 도구에서 다른 폰트를 눌러볼 수 있지만 제품에 채택한 글꼴은 페이퍼로지다.

## 실행과 소스

```sh
python3 legacy/design-prototypes/build_v4.py
python3 -m http.server 8767 --bind 127.0.0.1 --directory legacy/design-prototypes
```

- 레이아웃 / 스타일: `src/v4.html`, `src/v4.css`
- 화면 이동 / 글꼴 선택 / 크기 적응: `src/v4.js`
- `src/v4-engine.js`: v3 엔진의 디자인 시안용 사본. 로컬 분리 완료 시 카드 미리보기 갱신, v4 초기화 연결, 사진을 4:5로 빈 띠 없이 채우는 중앙 크롭을 적용했다. 기존 v3를 비교할 수 있도록 원본 v3 파일은 유지한다.
- `src/segment-worker.mjs`, `models/`, `vendor/`: 기존 로컬 추론 자산 유지.
- `provenance.json`: 사진, 글꼴, 모델 출처와 시안 상태.

## 검증과 한계

- 1440×1120 전체 흐름, 390×844 직접 사용 화면에서 배치와 동작 확인. 320px 폭에서 글꼴 선택과 가로 넘침 없음 확인.
- 세 폰트 실제 적용과 새로고침 후 선택 복원 확인. 같은 시안에서 바뀌며 글꼴별 비교 카드는 고유 서체를 유지한다.
- 시작 → 사진 선택 → 인물 편집 → 오른쪽 펼침 → 드래그로 길이 86 → 66 → 실행 취소 86 복원 → 피사체 보정 진입 확인.
- 일반 JPG를 로컬 파일 선택기로 불러와 효과 미선택 상태로 시작, 기기 내 분리 후 사용자가 직선을 선택하고 저장 미리보기로 이동하는 흐름 확인. QA 사진은 rembg 공식 예제이며 앱 자산에 포함하지 않았다.
- 브라우저 오류·경고 로그 없음. JavaScript 문법과 HTML/JS ID 연결 검사 통과.
- 기존 동작 제약 유지: 작은 마스크 모델은 머리카락·가는 구조물 등에서 경계가 거칠 수 있다. 입력 캐시는 960×1200, JPG 출력은 1440×1800 확대이며 원본 해상도 보존이 아니다.
- 실제 다운로드 완료는 검증하지 않았다. 이전 인앱 브라우저의 blob 링크 열기 차단을 재시도하거나 우회하지 않고 미리보기까지 검증했다.
- Android/V20 성능, 네이티브 글꼴 렌더링, 동적 글자 크기 대응은 별도 검증이 필요하다. 이번 결과는 HTML UI 제안이다.

## 샘플과 작품 크기 개선 — 2026-10-11

- 기존 샘플 대신 `assets/chrome-muse.png`, `assets/midnight-coupe.png`, `assets/electric-bloom.png`를 v4에 연결했다. 모두 내장 image_gen으로 생성한 원본 사진이며, 효과는 앱의 실제 스트레치 엔진이 만든다. 전체 프롬프트와 생성 경로는 `assets/v4-sample-prompts.json`에 있다. 기존 샘플과 v1–v3는 유지한다.
- 샘플과 가져온 사진 모두 비율을 유지한 채 4:5를 채운다. `Math.max`로 스케일을 정하고 중앙 크롭하므로 기존 회색 빈 띠가 사라진다. 가장자리 일부가 잘릴 수 있으며 사진 선택 화면에 안내한다. 위치를 옮기는 크롭 도구는 이번 범위에 넣지 않았다.
- 분리 모델, 색 샘플링, 효과, 저장은 같은 크롭 이미지와 좌표를 사용한다. 사용자 사진에 효과를 자동 적용하지 않는 흐름을 유지한다. 기본 바탕은 원본 사진이다.
- 편집 미리보기의 304px 상한과 남은 높이에 따른 강제 축소를 제거했다. 조작부 간격을 줄이고, 직접 사용 화면은 내용 높이에 따라 스크롤한다. 작은 화면에서도 사진 크기를 우선한다.
- 저장 미리보기의 기울임과 흰 액자, 247px 상한을 제거했다. 편집과 동일한 폭으로 정면 표시한다.
- 390px 화면에서 편집/저장 이미지 폭 342px, 앱 화면 폭 370px(약 92%) 확인. 320px 화면은 이미지 폭 274px, 가로 넘침 없음 확인.
- 새 샘플의 실제 분리와 가로/세로 스트레치, 드래그 길이 86→100 및 실행 취소 86, 바탕 패널 배치 확인. 가로 JPG(600×399)를 가져와 빈 띠 없이 중앙 크롭되는 것과 로컬 분리→곡선→저장 미리보기 확인. 최종 콘솔 오류/경고 없음. 파일 다운로드 완료는 이번에도 검증하지 않았다.
