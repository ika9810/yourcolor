# YourColor Google Play 출시 기록

최종 갱신: 2026-10-14. 이 문서는 `com.robotics.yourcolor`의 **기존 앱 업데이트**를 기록합니다. 새 픽셀 스트레치 앱 `versionCode=4`, `versionName=2.0.0`은 사용자 승인에 따라 2026-10-13 **프로덕션에 게시됐습니다.** 당시 Play 프로덕션 대시보드는 `활성 / 최신 출시 버전 4 (2.0.0)`, 대상 177개 국가/지역으로 표시했습니다. 프로덕션 출시 탭은 `Google Play에 제공됨`, 콘솔 표시 게시 시각은 2026-10-13 오후 2:47이었습니다. 이전 공개 버전은 2022년의 코드 1이었고 코드 2·3은 출시하지 않았습니다.

## 현재: 코드 6 (2.0.2) 공개

- 코드 5(2.0.1)는 Play에 업로드됐지만 비활성 상태입니다. 이 버전 코드를 다시 사용할 수 없어 브랜딩 업데이트는 코드 6으로 제출했습니다. **현재 프로덕션 활성 버전은 코드 6(2.0.2)**입니다.
- 코드 6 릴리스 APK·AAB를 생성하고 APK 출력 메타데이터의 패키지명 `com.robotics.yourcolor`, `versionCode=6`, `versionName=2.0.2`를 확인했습니다. AAB SHA-256은 `d1c76a3c94f3661f3f9bf783d8668610c8933ef5372ebe9424f5b6ed6e5a73ff`, APK SHA-256은 `95fce7984eb2e10ad5f1901a6fbc99d50afa375f127b0d4a38257f56fe05ab0b`입니다. `jarsigner -verify`는 AAB 서명을 확인했고 번들에 `adi-registration.properties`는 없습니다. 새 한국어·영어 개인정보처리방침 사본도 번들에 포함돼 있습니다.
- Play는 코드 6 AAB를 접수했고, 프로덕션 100% 출시 설정과 스토어 등록정보를 포함한 **변경사항 8건을 2026-10-13 Google 검토에 제출**했습니다. 관리형 게시를 꺼서 승인 후 자동 게시되도록 설정했습니다. Play Console에는 코드 6이 2026-10-14 오전 2:51(미 동부) 게시된 것으로 표시됩니다. 프로덕션 출시 상태는 `Google Play에 제공됨`, 출시는 100%이며 게시 개요에는 대기 중인 변경사항이 없습니다. 관리형 게시는 꺼져 있습니다.
- 한국어·영어(미국·캐나다) 공개 스토어에 2.0.2와 앱 이름 `yourcolor - 나만의 pixel stretch`, 새 파란 리본 아이콘, 꽃 전후 비교 기능 그래픽, 지역별 첫 스크린샷과 설명이 반영된 것을 확인했습니다. 공식 한국어 짧은 설명은 `사진 속 색을 펼쳐 만드는 나만의 픽셀 스트레치.`입니다. [한국어 문안](PLAY_STORE_KO.md)과 [영어 문안](PLAY_STORE_EN.md)에 코드 6 새 소식을 기록했습니다.
- 공개 [개인정보처리방침](https://ika9810.github.io/yourcolor-privacy/)은 HTTP 200으로 열리고, Play 정책 센터에는 `발견된 문제 없음`이 표시됩니다. 2026-10-14 오전 확인 시 사전 출시 보고서는 아직 없고 Android vitals의 사용자 체감 충돌·ANR 목록에도 결과가 없습니다. 게시 초기라 진단 데이터는 아직 제한적입니다.
- 저장소 마감 정리에서는 앱 자산에 포함된 샘플 생성 기록의 개인 로컬 경로만 공개용 문구로 바꿨습니다. 따라서 이 정리 이후의 코드 6 재빌드는 **이미 Play에 제출한 위 SHA-256 아티팩트와 바이트 단위로 같지 않습니다.** 새 AAB를 제출하지 않았으며 다음 출시에는 새 versionCode를 사용해야 합니다.

## 코드 4의 배포·서명 이력

- 기존 앱과 패키지명 `com.robotics.yourcolor`를 Play Console에서 대조했습니다. Play App Signing이 켜져 있습니다. 기존 프로덕션 코드 1의 공식 Play 서명 APK와 코드 4의 공식 Play 서명 APK를 확보했습니다. API 37 에뮬레이터에서 코드 1 설치 후 코드 4 공식 APK를 `install -r`로 설치해 성공했습니다. `firstInstallTime`과 앱 전용 파일의 SHA-256이 유지되고 코드 4가 정상 실행됐습니다. 검증 로그는 [`evidence/play-v1-to-v4-update.txt`](evidence/play-v1-to-v4-update.txt)입니다.
- 새 업로드 키·비밀번호·서명 설정은 Git 밖의 비공개 보관함에 있습니다. 세 파일은 Git에서 제외하며 내용이나 실제 로컬 경로는 문서·로그에 기록하지 않습니다. 로컬 컴퓨터를 정리하기 전 별도의 암호화 백업과 복원을 확인해야 합니다. Play에 표시된 새 업로드 인증서 SHA-256은 `4B:CB:86:A3:37:A0:F9:C0:83:AE:E7:E0:04:A8:B7:EA:4B:44:93:BB:C5:BA:F0:70:51:78:86:BE:69:C6:61:00`이고 로컬 후보 키와 일치했습니다.
- 키 사용 대기 시간은 끝났습니다. Play는 2026-10-13에 새 키로 서명한 코드 2·3·4 AAB를 접수했습니다. 코드 4는 내부 테스트에 출시됐고 이후 프로덕션에도 게시됐습니다. 코드 2·3은 출시하지 않았습니다. Play의 Android 개발자 인증 대시보드에는 이 앱이 **등록됨 / 소유권 확인됨**으로 표시됩니다. 별도의 앱 서명 APK 소유권 증명은 요구되지 않았습니다.
- 코드 4 당시 AAB의 SHA-256은 `528d88439777f5940bb74011094b170611cc96f279643c04135000e1246595ab`, 로컬 업로드 키 서명 APK의 SHA-256은 `a021b9fd289fbb046ffaa2dc68e9fff47369c7281d4721017bb3710a486fa694`입니다. 현재 빌드 출력 경로의 파일은 코드 6으로 교체됐습니다. Play에서 내려받은 별도 서명 코드 4 APK의 SHA-256은 `074c9e8b106196f38c8ed7377e02ac8bd70feeb6eaa74d587f369bc86ec91951`입니다. 계정별 `adi-registration.properties`는 배포 소스에서 제거했고 당시 AAB 내부 목록에도 없었습니다. 빌드 설정은 해당 파일이 다시 나타나면 빌드를 중단합니다. 비밀 키·비밀번호 파일은 번들과 Git에 포함하지 않습니다.

## 코드 4의 스토어·정책 게시 이력

- 코드 4 공개 당시 앱 이름은 `YourColor`, 분류는 **사진**이며 태그는 사진·사진 편집기·예술/디자인입니다. 기존 퍼스널 컬러 진단 앱에서 기능이 크게 바뀌므로 이 사실을 당시 릴리스 노트에 명시했습니다. 코드 6 제출용 문안은 위에 연결한 파일에 따로 기록했습니다.
- 기본 스토어 언어는 영어(미국)이고 영어(캐나다)·한국어 등록정보를 추가했습니다. 영문 휴대전화 스크린샷은 미국·캐나다에 각각 4장, 한국어는 6장입니다. 새 아이콘·기능 그래픽을 저장하고 구버전 태블릿 스크린샷은 제거했습니다. AI 생성 샘플 사진이 든 자산에는 Play의 AI 애셋 라벨을 지정했습니다.
- 공개 정책 주소는 <https://ika9810.github.io/yourcolor-privacy/>입니다. 코드 4 공개 시점에는 HTTP로 받은 본문과 당시 로컬 `../../legal/android-privacy.html`의 SHA-256이 모두 `8496df5e319858c2e3c5e949de5fe44fb2865fca2f59064b9c1d2180c7e6e87d`로 일치했습니다. 코드 6 제출 전 공개 정책 페이지도 버전 1의 시점 표현에 맞춰 수정했고, 공개 페이지와 현재 로컬 사본의 SHA-256이 모두 `1bb8aaa1c9af15209aee52a8d657b9eb201727dfce53db00f2f1ba03d5d89608`로 일치하는 것을 확인했습니다.
- Play에 금융·건강 기능 없음, 정부 앱 아님, 코드 4의 광고 ID 미사용을 신고했습니다. 이전 코드 1에는 광고·분석 SDK가 있었으므로 데이터 보안 양식에는 그 버전의 대략적 위치(IP 추정), 앱 상호작용, 진단, 기기/기타 ID의 수집·공유 및 광고·분석·사기 방지 목적을 반영했습니다. 코드 4에는 인터넷 권한과 광고·분석 SDK가 없습니다. 게시 후 Play 데이터 보안 공개 표기와 배포 중인 버전 범위를 다시 확인해야 합니다.
- 공개 문의 주소는 `legendspeeches@gmail.com`이고 연결되지 않는 `yourcolor.kr` 주소는 제거했습니다. 앱은 무료이며 프로덕션 대상은 미국·캐나다·한국을 포함한 177개 국가/지역입니다. 계정·결제·광고가 없는 사진 편집 앱이라는 현재 앱 액세스·대상 연령·콘텐츠 등급 선언을 다시 대조했습니다.
- 스토어·앱 콘텐츠와 코드 4 비공개 Alpha·프로덕션을 포함한 **15개 변경사항**은 Google 검토를 통과했습니다. 사용자 승인에 따라 관리형 게시 상태에서 Play Console의 **`변경사항 15개 게시` → `변경사항 출시`**를 실행했고 **`변경사항이 게시되었습니다.`** 확인 문구를 봤습니다. 프로덕션 대시보드와 출시 탭에서 코드 4 제공 상태를 재확인했습니다. 관리형 게시 설정은 공개 시점을 제어하는 데 사용했습니다.

## 코드 4의 로컬 검증과 알려진 한계

- 코드 4 릴리스 APK·AAB 빌드가 성공했습니다. API 24 에뮬레이터에서 연결 테스트 9개 통과·API 29 이상 전용 1개 건너뜀, API 37에서 10개 통과했습니다. API 36의 **16KB 페이지 크기 에뮬레이터**에서는 최종 전체 계측 검사 **10개가 한 번에 통과**했습니다. 초기 검사에서 8px 스크롤 위치 차이로 실패한 이력과 최종 재검사 로그는 [검증 기록](VALIDATION.md)에 구분했습니다. 8개 화면 프로필도 통과했습니다.
- 코드 3의 API 24 홈 시작 버튼은 잘렸지만 코드 4에서는 같은 화면 크기로 다시 확인했습니다. Pixel Fold 에뮬레이터의 `OPENED`·`CLOSED`·`HALF_OPENED` 상태와 가로 회전에서 편집 상태 유지도 확인했습니다. 실제 제조사 힌지와 One UI 동작은 별도입니다.
- Play Bundle Explorer는 코드 4에서 **16KB 페이지 크기 지원**을 감지했습니다. 이 신호와 에뮬레이터 실행은 서로 다른 검증입니다. 최종 코드 4에서 `assembleRelease`, `bundleRelease`, `lintVitalRelease` 성공을 확인했습니다. `testDebugUnitTest`와 `lintDebug`는 코드 4 수정 후 다시 실행한 결과가 아직 없습니다.
- 사용자는 실기기를 보유하지 않으며 실기기 시험은 이번 출시의 필수 조건에서 제외했습니다. 에뮬레이터 및 Play 사전 출시 보고서로 API 24·최신 API, 폴더블 크기·회전·접힘/펼침과 16KB 페이지 크기 환경을 가능한 범위에서 확인합니다. Z Fold의 One UI·실제 힌지·실기기 성능과 LG V20 실기기 동작은 확인되지 않은 범위로 명시합니다.
- 게시 **전** Play 정책 상태에는 코드 1에 대한 대상 API 35/36, 16KB 페이지 크기, 구형 SDK 경고가 남아 있었습니다. 코드 4는 `targetSdk 36`이며 16KB 지원과 에뮬레이터 실행을 확인했습니다. 게시 직후 정책 화면에도 해당 경고가 남아 있었으므로 Play 상태 갱신을 계속 확인해야 합니다. 한국어 공개 스토어에서는 버전 2.0.0, 새 설명·스크린샷·사진 분류와 데이터 보안 항목을 확인했습니다. 코드 4 프로덕션 비교 화면에는 지원 기기 축소(전화 1,630개, 태블릿 404개, TV 3개)가 표시됐습니다. 대부분 `minSdk 24`로 올라간 영향이며 Play가 표시한 전화·태블릿의 영향 받는 기존 설치 수는 각각 0입니다. TV의 영향 설치 수는 확인되지 않았습니다.

## 코드 6 공개 확인 및 남은 관찰 항목

1. Play 프로덕션 활성 버전과 한국어·영어(미국·캐나다) 공개 스토어의 2.0.2, 앱 이름·설명·아이콘·기능 그래픽·첫 스크린샷을 확인했습니다. Play Console에는 대기 중인 변경사항이 없습니다.
2. 공개 개인정보처리방침 페이지와 앱 내 한국어·영어 정책 사본의 시점 표현은 동기화했습니다. 공개 페이지 접속과 Play 정책 센터의 문제 없음 상태를 확인했습니다.
3. 사전 출시 보고서는 아직 생성되지 않았고 Android vitals 충돌·ANR 목록은 게시 초기 확인 시 결과가 없습니다. 이후 결과가 나오면 실제 결함과 정책 경고를 확인합니다.
4. 6시간 간격의 `YourColor 배포 후 확인` 작업은 코드 6 공개와 초기 상태 확인을 마쳐 2026-10-14 일시 중지했습니다.
