## 코드 4의 로컬 검증과 알려진 한계

- 코드 4 릴리스 APK·AAB 빌드가 성공했습니다. API 24 에뮬레이터에서 연결 테스트 9개 통과·API 29 이상 전용 1개 건너뜀, API 37에서 10개 통과했습니다. API 36의 **16KB 페이지 크기 에뮬레이터**에서는 최종 전체 계측 검사 **10개가 한 번에 통과**했습니다. 초기 검사에서 8px 스크롤 위치 차이로 실패한 이력과 최종 재검사 로그는 [검증 기록](../../document/android-validation.md)에 구분했습니다. 8개 화면 프로필도 통과했습니다.
- 코드 3의 API 24 홈 시작 버튼은 잘렸지만 코드 4에서는 같은 화면 크기로 다시 확인했습니다. Pixel Fold 에뮬레이터의 `OPENED`·`CLOSED`·`HALF_OPENED` 상태와 가로 회전에서 편집 상태 유지도 확인했습니다. 실제 제조사 힌지와 One UI 동작은 별도입니다.
- Play Bundle Explorer는 코드 4에서 **16KB 페이지 크기 지원**을 감지했습니다. 이 신호와 에뮬레이터 실행은 서로 다른 검증입니다. 최종 코드 4에서 `assembleRelease`, `bundleRelease`, `lintVitalRelease` 성공을 확인했습니다. `testDebugUnitTest`와 `lintDebug`는 코드 4 수정 후 다시 실행한 결과가 아직 없습니다.
- 사용자는 실기기를 보유하지 않으며 실기기 시험은 이번 출시의 필수 조건에서 제외했습니다. 에뮬레이터 및 Play 사전 출시 보고서로 API 24·최신 API, 폴더블 크기·회전·접힘/펼침과 16KB 페이지 크기 환경을 가능한 범위에서 확인합니다. Z Fold의 One UI·실제 힌지·실기기 성능과 LG V20 실기기 동작은 확인되지 않은 범위로 명시합니다.
- 게시 **전** Play 정책 상태에는 코드 1에 대한 대상 API 35/36, 16KB 페이지 크기, 구형 SDK 경고가 남아 있었습니다. 코드 4는 `targetSdk 36`이며 16KB 지원과 에뮬레이터 실행을 확인했습니다. 게시 직후 정책 화면에도 해당 경고가 남아 있었으므로 Play 상태 갱신을 계속 확인해야 합니다. 한국어 공개 스토어에서는 버전 2.0.0, 새 설명·스크린샷·사진 분류와 데이터 보안 항목을 확인했습니다. 코드 4 프로덕션 비교 화면에는 지원 기기 축소(전화 1,630개, 태블릿 404개, TV 3개)가 표시됐습니다. 대부분 `minSdk 24`로 올라간 영향이며 Play가 표시한 전화·태블릿의 영향 받는 기존 설치 수는 각각 0입니다. TV의 영향 설치 수는 확인되지 않았습니다.

## 코드 6 검토·게시 후 확인 항목

1. Google 검토 결과와 자동 게시 상태를 확인합니다. 승인 후 Play 프로덕션 대시보드와 공개 스토어에 코드 6(2.0.2)이 표시되는지 확인합니다. 100% 출시 설정만으로 공개됐다고 기록하지 않습니다.
2. 한국어·영어(미국·캐나다) 앱 이름·짧은 설명·아이콘·기능 그래픽·휴대전화 스크린샷 및 AI 애셋 라벨을 지역별 공개 스토어에서 확인합니다.
3. 공개 개인정보처리방침 페이지와 앱 내 한국어·영어 정책 사본의 시점 표현을 맞추고, 데이터 보안 신고·정책 경고·사전 출시 보고서·충돌 및 ANR 상태를 확인합니다.

## 코드 4 게시 직후의 확인 기록

1. 게시 직후에도 남은 코드 1 관련 대상 API·16KB·SDK 경고가 Play에서 갱신되는지 확인합니다. 한국어 공개 스토어의 버전 2.0.0, 새 설명·이미지·사진 분류, 데이터 보안 항목은 확인했습니다. 미국·캐나다의 지역별 문안·이미지와 공개 개인정보처리방침 연결도 추가 확인합니다. Play 대시보드의 `활성 / 최신 출시 버전 4 (2.0.0)` 및 177개 국가/지역은 이미 확인했습니다.
2. Play 사전 출시 보고서는 게시 직후에도 개요에 **‘아티팩트를 업로드하여 사전 출시 보고서 생성’** 안내만 보여 결과가 없었습니다. 추후 결과가 나타나면 충돌·호환성·정책 경고에 대응합니다. 테스터 이메일이나 사용자 실기기를 필수 선행 조건으로 두지 않습니다.
3. 코드 4의 `testDebugUnitTest`·`lintDebug`는 마지막 수정 후 재실행 결과가 없으므로 필요하면 실행합니다. 16KB 전체 계측 테스트는 최종 10개 모두 통과했습니다. 실기기에서만 확인 가능한 범위는 [검증 기록](../../document/android-validation.md)에 남깁니다.
4. 6시간 간격의 Codex heartbeat `YourColor 배포 후 확인`을 다시 활성화했습니다. 2026-10-15 오후 3시(미 동부)까지 공개 버전·정책 경고·사전 출시 보고서·충돌 및 ANR 상태를 확인하고, 상태 변화나 조치가 필요할 때만 알립니다. Muse의 시간당 감시는 별도 일정으로 등록되지 않았습니다.
