YourColor 개인정보 처리방침
시행일: 2026년 10월 11일

1. 버전 2.0.0 이후: 처리하는 정보와 목적
YourColor는 사용자가 Android 사진 선택기를 통해 고른 사진을 픽셀 스트레치 편집과 피사체 분리에 사용합니다. 사진은 사용자가 선택할 때만 접근하며, 앱의 전용 캐시에 복사해 기기 안에서 처리합니다. 피사체 분리에는 앱에 포함된 U²-NetP 모델을 사용합니다.

2. 버전 2.0.0 이후: 전송과 제3자 제공
버전 2.0.0 이후에는 인터넷 권한, 계정, 광고·분석 SDK와 자체 서버가 없습니다. 이 버전은 선택한 사진이나 편집 결과를 개발자 또는 제3자 서버로 전송하지 않습니다. 사용자가 시스템 저장 화면에서 외부 서비스를 저장 위치로 직접 선택하는 경우, 그 서비스의 처리는 해당 서비스의 정책에 따릅니다.

3. 버전 2.0.0 이후: 보관과 삭제
선택한 사진의 앱 전용 임시 복사본은 사진을 바꾸거나 홈으로 돌아갈 때 삭제합니다. 새 앱 세션을 시작할 때 남은 임시 사진을 정리합니다. 편집 중 생성한 임시 JPG는 앱의 캐시에 저장되며, 24시간이 지난 파일은 다음 앱 시작 때 삭제합니다. 사용자가 저장한 결과는 선택한 기기 사진 보관함 또는 저장 위치에 남고, 앱은 이를 자동으로 삭제하지 않습니다. 사용자는 기기의 사진·파일 앱에서 저장 결과를 직접 삭제할 수 있습니다. 앱 삭제 시 앱 전용 캐시도 삭제됩니다.

4. 기존 버전 1: 데이터 처리
현재 교체 중인 기존 버전 1(옛 이름 ‘너의퍼스널컬러는’)은 인터넷에 연결하고 외부 웹페이지를 열며 Google Mobile Ads 등 광고·분석 SDK를 포함합니다. 이 SDK를 통해 IP 주소(대략적인 위치 추정에 사용될 수 있음), 앱 상호작용, 진단 정보, 기기 또는 광고 식별자가 Google 등 SDK 제공자에게 전송될 수 있습니다. 이 정보는 광고 제공·측정, 사용 통계, 사기 방지에 이용될 수 있습니다. 전송 중에는 보안 연결을 사용합니다. SDK 제공자의 보관과 삭제 방식은 Google 개인정보처리방침(https://policies.google.com/privacy) 등 각 제공자의 정책을 따릅니다. 버전 2.0.0 이후에는 이 광고·분석 SDK가 포함되지 않습니다.

5. 보안과 권리
버전 2.0.0 이후에는 사진을 기기 안에서만 처리하고 앱 전용 공간에 임시 파일을 보관합니다. 별도의 회원 계정이나 개발자 서버 저장 데이터는 없습니다. 처리에 대한 문의나 삭제 요청은 아래 연락처로 보내 주세요. 기기에 저장한 결과의 삭제는 기기의 사진·파일 앱에서 직접 할 수 있습니다.
