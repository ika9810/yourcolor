# 개인정보처리방침 원본

[`android-privacy.html`](android-privacy.html)은 현재 Android 앱 정책의 저장소 사본입니다. 사용자에게 표시되는 공개 페이지는 별도 저장소 [ika9810/yourcolor-privacy](https://github.com/ika9810/yourcolor-privacy)의 [GitHub Pages](https://ika9810.github.io/yourcolor-privacy/)입니다. 이 파일만 수정해도 공개 페이지는 자동으로 바뀌지 않습니다.

앱 내부 한국어·영어 사본은 각각 `android/app/src/main/assets/privacy-policy.txt`, `privacy-policy-en.txt`입니다. 처리 방식이 바뀌면 이 세 사본과 공개 페이지, Play Console 데이터 보안 정보를 함께 검토하세요. 현재 연락처는 Play에 공개된 문의 이메일입니다.
